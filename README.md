# voloshins.js.org

Terminal-style portfolio site built with React + TypeScript + Vite.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Deploy to GitHub Pages

```bash
npm run deploy
```

The custom domain is configured via:

- `CNAME`
- `public/CNAME`

Both are set to `voloshins.js.org`.
